# Шаг 1. Актуализация ценностного предложения  

Для **HR-директора IT-компании (50–200 сотрудников)** в ситуации **регулярных увольнений ключевых специалистов и отсутствия честной обратной связи** решение **«AI-Exit»** обеспечивает **автоматический сбор и AI-анализ истинных причин ухода**, улучшая **экономию времени HR (10+ часов/мес) и снижение текучести за счёт выявления системных проблем** по сравнению с **Google Forms, Excel и личными встречами**, при условиях **гарантированной анонимности, соблюдения 152-ФЗ и запуска пилота за 2–4 недели**.

**Почему пользователь поверит (основания):**
1. **AI-анализ** предобучен на HR-датасетах и понимает русскоязычную терминологию («выгорание», «токсичный лид»).
2. **Чат-бот** повышает честность ответов за счёт анонимности и простоты прохождения.
3. **Экономическое обоснование:** стоимость подписки заведомо ниже стоимости замены одного IT-специалиста (3–9 окладов).

# Шаг 2. Декомпозиция ценности в пользовательский сценарий

**Основной сценарий:** Полный цикл exit-интервью от увольнения до управленческого инсайта

| Шаг | Действие | Роль |
| :--- | :--- | :--- |
| 1 | Сотрудник подаёт заявление об увольнении → статус в HRIS меняется на «Увольняется». | Система (триггер) |
| 2 | Сервис автоматически запускает персонализированный сценарий exit-интервью. | Система |
| 3 | Увольняющийся сотрудник получает ссылку на анонимный чат-бот в Telegram или адаптивную веб-форму. | Система |
| 4 | Сотрудник отвечает на 5–7 вопросов о причинах ухода, условиях работы, руководителе. | Пользователь (респондент) |
| 5 | Система автоматически анонимизирует ответы (удаляет email, IP, имя). | Система |
| 6 | AI-модуль классифицирует причины ухода («зарплата», «выгорание», «токсичный лид», «перегрузка»). | Система |
| 7 | HR-менеджер получает уведомление и видит в дашборде агрегированные данные и тренды. | HR |
| 8 | На основе инсайтов формируются задачи по удержанию (пересмотр вилок, смена тимлида). | HR |  

**Запасной сценарий:** Работа с «дремлющими» респондентами и повторное использование

| Шаг | Действие | Роль |
| :--- | :--- | :--- |
| 1 | Сотрудник не проходит опрос в течение 3 дней после получения ссылки. | Система |
| 2 | Сервис автоматически отправляет напоминание (push или в мессенджер). | Система |
| 3 | Сотрудник проходит опрос → данные уходят в AI-модуль (как в основном сценарии). | Пользователь / Система |
| 4 | HR-менеджер заходит в дашборд и хочет посмотреть детализацию по конкретному отделу. | HR |
| 5 | Система фильтрует данные по отделу и показывает топ-3 причины ухода. | Система |
| 6 | HR-менеджер выгружает анонимизированные цитаты для презентации основателю. | HR |
