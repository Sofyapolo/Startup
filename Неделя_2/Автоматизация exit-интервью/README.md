## Автоматизация exit-интервью

---

## Шаг 1. Фиксация идеи и проблемного контекста

**Идея:** Единый SaaS-сервис для автоматизации exit-интервью, объединяющий триггерные чат-боты, AI-аналитику текстовых ответов и дашборды для HR.

*Ключевая механика:*

1.  **Триггер:** Автоматически запускается сценарий при заявлении об увольнении.
2.  **Сбор:** Анонимный чат-бот в мессенджере проводит интервью.
3.  **Анализ:** Модель классифицирует причины (зарплата, лидер, выгорание), выявляет тональность и скрытые риски.
4.  **Действие:** HR получает готовый инсайт-отчет, а не сырые данные, что позволяет предотвращать будущие увольнения.

**Проблема:** HR-отделы теряют критическую информацию об истинных причинах текучести. Сотрудники боятся писать правду в открытых полях из-за риска «черной метки», бумажные анкеты и Google Forms заполняются «для галочки», компания не видит системных дыр, продолжая терять деньги на постоянном найме.

**Сценарий:**

* **Пользователь (ЛПР):** HR-директор / HR-бизнес-партнер / Основатель IT-компании.                                                                                                      * **Пользователь (Исполнитель):** Уходящий сотрудник (через бота), HR-менеджер (через дашборд).                                                                                          
* **Ситуация:** Сотрудник подает заявление → Запускается процесс оффбординга.                                                                                                            
* **Проблема:** Нет единой системы: данные собираются вручную/хаотично, игнорируются или анализируются слишком долго.                                                         
* **Последствия:**
   *  **Время:** Потеря 10+ часов HR в месяц на ручную сводку;
   *  **Деньги:** Прямые убытки из-за текучести (стоимость замены = 3–9 окладов);
   *  **Качество:** Снижение эффективности команды, выгорание оставшихся;
   *  **Риски:** Ухудшение Employer Brand, утечка знаний к конкурентам.

| :-------------------------------- | :------------------------------------------- | :------------------------------------------------------- | :----------------------------------------------- | :---------------------------------------------------------- | :------------------------------------------------ |

| **4. Госсектор**                  | Руководитель кадровой службы                 | Формальный подход, данные «для галочки», причины скрыты  | Бумажные формы по шаблонам, отсутствие аналитики | 44-ФЗ/223-ФЗ, низкая гибкость, приоритет регламентам        | Госзакупки (ЕИС), отраслевые форумы, министерства |

## Шаг 3. Выбор приоритетного сегмента

| Критерий                  | IT (Рост)  | Ритейл        | Enterprise            | Госсектор     |
| :------------------------ | :--------- | :------------ | :-------------------- | :------------ |
| **Выраженность проблемы** | Высокая    | Очень высокая | Умеренная (аналитика) | Низкая        |
| **Доступность**           | Высокая    | Средняя       | Низкая                | Низкая        |
| **Скорость решения**      | 2–6 недель | 1–3 месяца    | 6–18 месяцев          | 6–24 месяца   |
| **Барьеры внедрения**     | Низкие     | Средние       | Высокие               | Очень высокие |
| **Вероятность оплаты**    | Средняя    | Высокая       | Высокая               | Низкая        |

**Приоритет:** Сегмент 1 (IT/Tech, 50–200 сотрудников).  

**Аргументация:**
* **Баланс боль/деньги:** Дорогая текучесть, но нет сложных систем. Готовы платить за быстрое решение.
* **Низкие барьеры:** Облачная инфраструктура, пилот за 2–4 недели.
* **Обучение продукта:** Качественная обратная связь для отточки ИИ и UX.
* **Сарафанное радио:** Плотное сообщество IT-HR, низкий CAC.
* **Стратегия:** Плацдарм для масштабирования в ритейл и Enterprise.
* **Риск:** Ограниченный бюджет SMB (Смягчение: SaaS, гибкий тариф, акцент на ROI (< стоимости найма 1 сотрудника)).

|                        | Универсальные HR-платформы | SAP, Oracle, BambooHR, Personio | ○         | Дорого ($10k+), долгое внедрение, exit — второстепенно   |                                                      |
|                        | Engagement/опросы          | Culture Amp, Glint, Qualtrics   | ○         | Фокус на pulse, слабая автоматизация exit, нет чат-ботов |                                                      |
|                        | Конструкторы ботов         | ManyChat, Aimylogic             | ○         | Нет HR-логики, сборка с нуля, нет аналитики причин       |                                                      |
| **Ритейл (500+)**      | Ручные решения             | Бумага, Excel в 1С, телефон     | ●●●       | Низкая масштабируемость, задержки, ошибки ввода          | **Мобильный чат-бот + авто-интеграция с HRIS**       |
|                        | HR-платформы               | 1С:ЗУП, Битрикс24, SAP          | ●●        | Сложно для линейных менеджеров, нет сценариев под массу  |                                                      |
| **Enterprise (1000+)** | Универсальные HR-платформы | SAP, Oracle, Workday            | ●●●       | Безопасность, тендеры, сложная кастомизация              | **AI-модуль анализа причин как дополнение к HRIS**   |
|                        | BI/Analytics               | Power BI, Tableau               | ●●        | Требуют команду аналитиков, нет авто-инсайтов            |                                                      |
| **Госсектор**          | Регламентированные         | Бумажные формы, 1С:Кадры        | ●●●       | Приоритет регламента над эффективностью                  | **Цифровизация регламентных процессов с аналитикой** |

**Позиционирование:**
- **Фокус:** IT/Tech, 50–200 сотрудников.
- **УТП:** Единый контур: формы + чат-бот + AI-анализ + дашборд + сценарии.
- **Цена:** $50–300/мес (SaaS, pay-per-employee).
- **Время до результата:** Пилот за 2 недели.
- **Отстройка:** HR-first логика (сценарии под типы увольнений).
- **ROI:** Стоимость системы < стоимости найма 1 разработчика.
