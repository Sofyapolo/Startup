# Шаг 1. Определение «ядра роста» и целей

**Сегмент:** IT-компании 50–200 сотрудников (Scale-up). ЛПР: HR-директор.

**Сценарий:** HR регулярно теряет ключевых сотрудников, не понимает истинных причин ухода и тратит 10+ часов в месяц на ручную аналитику.

**Ценность:** Автоматический сбор и AI-анализ причин увольнений с готовыми рекомендациями по удержанию.

### Главный драйвер роста

**Выбранный драйвер:** B2B-канал продаж (партнёрства + контентное комьюнити)

**Почему:** Сегмент (HR-директора IT-компаний) сконцентрирован в профессиональных сообществах (Telegram, LinkedIn) и доверяет рекомендациям коллег. Партнёрства с HR-консультантами и интеграторами дают доступ к «тёплым» лидам.

### Цели на 3 и 12 месяцев

| Горизонт | Цель (метрика) | Значение |
| :--- | :--- | :--- |
| **3 месяца** | Количество платящих клиентов | ≥3 |
| | MRR (месячная выручка) | ≥$600 |
| | Конверсия из пилота в платёж | ≥30% |
| | Успешно завершённых sales-экспериментов | ≥4 из 6 |
| **12 месяцев** | Количество платящих клиентов | ≥20 |
| | ARR (годовая выручка) | ≥$48,000 |
| | Retention (клиентов через 6 месяцев) | ≥70% |
| | LTV / CAC | ≥3:1 |

# Шаг 3. Финансовый план на 12–24 месяца

### Допущения (базовый сценарий)

| Параметр | Значение | Обоснование |
| :--- | :--- | :--- |
| **Средний чек (ARPU)** | $199/мес | Тариф Pro (50–200 сотрудников). |
| **Конверсия из демо в платёж** | 25% | С учётом пилота (30% → 50% → среднее). |
| **Churn (отток)** | 5% в месяц | HR-инструменты обычно используют долго (B2B). |
| **COGS на клиента** | $30/мес | Инфраструктура (серверы, AI API), поддержка. |
| **Маркетинг/продажи** | $500/мес + 10% от выручки | Лидогенерация, контент, комиссии. |
| **Разработка (фикс)** | $2,000/мес | 1 разработчик (фриланс), DevOps. |
| **Операционные** | $500/мес | CRM, юридическое сопровождение, связь. |

### Воронка продаж (базовый сценарий, помесячно)

| Месяц | 1 | 2 | 3 | 6 | 9 | 12 | 18 | 24 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Лиды** | 10 | 12 | 15 | 20 | 25 | 30 | 35 | 40 |
| **Демо** (40%) | 4 | 5 | 6 | 8 | 10 | 12 | 14 | 16 |
| **Платящие новые** (25% от демо) | 1 | 1.25 | 1.5 | 2 | 2.5 | 3 | 3.5 | 4 |
| **Платящие накоплено** (с учётом churn 5% в месяц) | 1 | 2.1 | 3.2 | 7.5 | 12.8 | 18.9 | 29.1 | 41.2 |
| **MRR** ($199 × платящие) | $199 | $418 | $637 | $1,493 | $2,547 | $3,761 | $5,791 | $8,199 |

### Три сценария (ARR на конец периода)

| Сценарий | Конверсия демо → платёж | Churn (мес) | ARPU | ARR (12 мес) | ARR (24 мес) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Консервативный** | 15% | 7% | $149 | ~$18,000 | ~$42,000 |
| **Базовый** | 25% | 5% | $199 | ~$45,000 | ~$98,000 |
| **Оптимистичный** | 35% | 3% | $299 | ~$85,000 | ~$210,000 |

### Потребность в финансировании (базовый сценарий)

| Показатель | 12 месяцев | 24 месяца |
| :--- | :--- | :--- |
| **Выручка** | $45,000 | $98,000 |
| **COGS** | $7,000 | $15,000 |
| **Валовая прибыль** | $38,000 | $83,000 |
| **Маркетинг/продажи** | $10,000 | $20,000 |
| **Разработка (фикс)** | $24,000 | $48,000 |
| **Операционные** | $6,000 | $12,000 |
| **Итого затраты** | $40,000 | $80,000 |
| **Операционный результат** | **-$2,000** | **+$3,000** |
| **Накопленный cashflow** | -$18,000 | -$15,000 |

**Вывод:** Проект выходит на операционную безубыточность к 18–20 месяцу. До этого требуется **$15,000–20,000 внешнего финансирования** (или доход от фриланса/основателей).

# Шаг 4. Анализ чувствительности

### Матрица чувствительности (ARR за 12 месяцев, $k)

| Конверсия \ ARPU | $149 | $199 | $299 |
| :--- | :--- | :--- | :--- |
| **15%** | $18 | $22 | $34 |
| **25%** | $34 | $45 | $67 |

**Вывод:** Главный рычаг — **конверсия из демо в платёж** (качество демо, онбординга, ценности). Второй по важности — **ARPU** (апсейл, расширение тарифов).

# Шаг 5. Оценка компании (2 метода)

### Метод 1: Венчурный метод (Venture Capital Method)

| Параметр | Базовый сценарий | Оптимистичный |
| :--- | :--- | :--- |
| Горизонт прогноза | 4 года | 4 года |
| ARR на 4 год | $300,000 | $800,000 |
| Мультипликатор выхода (EV/ARR) | 5x | 7x |
| Exit Value | $1.5M | $5.6M |
| Требуемая доходность инвестора (IRR) | 40% (x1.4 в год) | 40% |
| Фактор дисконтирования (4 года) | (1.4)^4 ≈ 3.84 | 3.84 |
| Post-money valuation (сегодня) | $1.5M / 3.84 ≈ $390k | $5.6M / 3.84 ≈ $1.46M |
| **Диапазон pre-money (при инвестиции $100k)** | **~$290k – $1.36M** | |

### Метод 2: Мультипликаторы (Comparables)

**Аналоги для сравнения:**

| Компания | Сегмент | ARR | Мультипликатор EV/ARR |
| :--- | :--- | :--- | :--- |
| PeopleForce (аналог в СНГ) | HR-tech (SMB) | $2M | 4–6x |
| BambooHR (публичный аналог) | HR-tech (SMB) | $200M | 8–10x |
| Российские SaaS-стартапы (ранняя стадия) | B2B SaaS | $100k–500k | 2–4x |

**Применяемый мультипликатор:** 3–5x (ранняя стадия, риски).

**Расчёт диапазона:**

| Показатель | Консервативно | Базово | Оптимистично |
| :--- | :--- | :--- | :--- |
| ARR через 12 месяцев | $18k | $45k | $85k |
| Мультипликатор | 3x | 4x | 5x |
| **Оценка компании** | **$54k** | **$180k** | **$425k** |

### Итоговый диапазон оценки

| Метод | Диапазон (pre-money) |
| :--- | :--- |
| Венчурный метод | $290k – $1.36M |
| Мультипликаторы | $54k – $425k |
| **Консенсус (усреднённый с учётом рисков)** | **$150k – $500k** |

**Факторы, снижающие оценку:** ранняя стадия (нет ARR), отсутствие product-market fit, зависимость от основателей, рыночные риски.

**Факторы, повышающие оценку:** сильная команда, понятная проблема, первые LOI/пилоты, понятный канал привлечения.

# Шаг 6. План повышения оценки

### 5 факторов + действия

| Фактор | Текущее состояние | Цель через 2–3 месяца | Действия |
| :--- | :--- | :--- | :--- |
| **1. Наличие платящих клиентов (ARR)** | 0 | ≥3 платящих ($600+ MRR) | Запустить sales test (30 контактов), заключить пилоты, перевести в платёж. |
| **2. Конверсия пилот → платёж** | Не измерялась | ≥30% | Улучшить онбординг, показывать быстрый ROI, собирать возражения. |
| **3. Retention / повторное использование** | Нет данных | 3-месячный retention ≥60% | Авто-напоминания, дашборд с инсайтами, поддержка. |
| **4. Подтверждение канала (CAC)** | Не измерялся | CAC ≤ $500 | Систематизировать LinkedIn-сообщения, Telegram-посты, партнёрства. |
| **5. Доказательство спроса (LOI / пилоты)** | 0 | ≥3 LOI или пилота | Прямые переговоры с HR-директорами, презентация ценности. |
