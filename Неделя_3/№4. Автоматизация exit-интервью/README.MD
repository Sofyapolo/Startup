## AI-сервис для автоматизации exit-интервью

## Шаг 1. Уточнение выбранного сегмента

**Границы сегмента:**
Мы рассматриваем сегмент **HR-директоров и основателей IT-компаний стадии Scale-up (50–200 сотрудников)**, поскольку именно у них критически высокая текучесть (15–30%/год), создающая прямые финансовые убытки, при этом они обладают достаточной гибкостью для быстрого внедрения пилотных решений (2–4 недели) и доступностью через профессиональные сообщества.

## Шаг 2. Сбор исходных наблюдений (Desk Research)

1.  **Финансовый сигнал:** Стоимость замены сотрудника в IT составляет 3–9 окладов, что делает ROI инструментов удержания очевидным для бизнеса.
2.  **Операционный сигнал:** HR-специалисты теряют 10+ часов в месяц на ручную сводку данных из Excel после увольнений.
3.  **Поведенческий сигнал:** Сотрудники боятся писать правду в открытых полях стандартных форм, предпочитая формальные отговорки.
4.  **Технологический сигнал:** Существующие Enterprise-решения (Culture Amp, Qualtrics) слишком дороги и сложны для компаний до 200 человек.
5.  **Инструментальный сигнал:** Популярные замены (Google Forms, Excel) не дают аналитики, данные копиятся «мертвым грузом».
6.  **Трендовый сигнал:** Удаленная работа снижает эффективность личных exit-интервью, цифровые каналы становятся стандартом.
7.  **Барьерный сигнал:** Существует страх передачи HR-данных в зарубежные компании из-за 152-ФЗ и требований безопасности.
8.  **Интеграционный сигнал:** Без авто-триггера при увольнении (интеграция с HRIS) ценность продукта резко падает из-за ручного запуска.
9.  **Рыночный сигнал:** В сегменте 50–200 сотрудников нет специализированных недорогих решений с AI-аналитикой (дыра между Google Forms и Talenteria).
10. **Управленческий сигнал:** HR-функция трансформируется в Data-Driven, руководители требуют обоснованных решений на основе данных, а не интуиции.

## Шаг 4. Персона (Persona)

**Имя:** Алексей, HR-директор  
**Компания:** IT-Scale-up (120 сотрудников, разработка ПО)  
**Возраст:** 35 лет  
**Опыт:** 8 лет в HR, 3 года на текущем месте.

- **Краткое описание:** Алексей загружен операционкой, хочет стать стратегическим партнером бизнеса, но тонет в текучке и таблицах. Ценит время, боится ошибиться с бюджетом на инструменты.
- **Цели:**
  *  Снизить текучесть ключевых разработчиков.
  *  Автоматизировать рутинный сбор обратной связи.
  *  Предоставлять основателям отчеты с инсайтами, а не просто цифры.
- **Боли/фрустрации:**
  *  Сотрудники пишут «по семейным обстоятельствам», скрывая реальные проблемы.
  *  Нет времени анализировать текстовые ответы вручную.
  *  Дорогие Enterprise-системы не окупаются на текущем штате.
  *  Потеря знаний при уходе сотрудников без фиксации причин.
- **Контекст работы:** Удаленная команда, высокий темп, ограниченный HR-бюджет, давление со стороны основателей по удержанию.
- **Текущий процесс:** Увольнение → ссылка на Google Form → выгрузка в Excel → ручное чтение → сводная таблица для директора (занимает дни).
- **Критерии выбора (Топ-5):**
  *  Стоимость внедрения и подписки.
  *  Качество AI-аналитики (понятные инсайты).
  *  Анонимность для сотрудников (честность ответов).
  *  Скорость запуска (не дольше 2 недель).
  *  Соответствие 152-ФЗ.
- **Возражения/риски:**
  *  «Сотрудники все равно не будут писать правду боту».
  *  «Это еще одна система, которую нужно интегрировать».
  *  «Безопасность персональных данных под угрозой».
- **Где «обитает»:** Telegram-каналы про HR-tech, LinkedIn, конференция HR-Tech Conf, профильные чаты HR-директоров.

## Шаг 6. Карта инсайтов и гипотез

### Инсайты (5–7)

1.  **Цена ошибки:** Потеря одного сотрудника в IT стоит дороже, чем годовая подписка на сервис для всей компании.
2.  **Честность канала:** Анонимный чат-бот воспринимается как более безопасный канал для правды, чем форма с подписью или личная встреча с HR.
3.  **Время HR:** Основная боль не в сборе данных, а в их агрегации и анализе (Excel-ад).
4.  **Сегментная дыра:** Между бесплатными формами и дорогими Enterprise-системами есть вакуум для SMB/Scale-up.
5.  **Триггер действия:** HR готов платить только если видит связь между отчетом и реальными действиями по удержанию.
6.  **Барьер доверия:** Без гарантий безопасности (152-ФЗ) сделка не состоится, даже при высокой боли.
7.  **Интеграция = Ценность:** Ручной запуск интервью снижает конверсию использования, нужен авто-триггер из HRIS.

### Гипотезы

1.  **H1 (ROI):** Если сервис предотвратит хотя бы 1 увольнение в квартал, это окупит годовую стоимость подписки для компании.
2.  **H2 (Честность):** Использование чат-бота повысит долю честных ответов о причинах ухода на 30% по сравнению с Google Forms.
3.  **H3 (Внедрение):** HR-директор готов внедрить пилот за 2–4 недели, если не требуется сложная интеграция на старте.
4.  **H4 (Анонимность):** Гарантия анонимности является ключевым фактором выбора для сотрудников чаще, чем удобство интерфейса.
5.  **H5 (Действие):** HR-специалисты чаще используют отчеты, где есть конкретная рекомендация («инсайт принят к действию»), чем просто графики.
6.  **H5 (Канал):** Привлечение через профессиональные HR-сообщества снизит CAC по сравнению с контекстной рекламой.
