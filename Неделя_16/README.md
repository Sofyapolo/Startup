## 2. Формализация ключевого сценария и «точек контроля»

### 2.1. Основной end-to-end сценарий (12 шагов) — финальная версия

| Шаг | Действие | Роль | Контрольная точка |
| :--- | :--- | :--- | :--- |
| 1 | HR переходит на лендинг и нажимает «Регистрация» | HR | Вход в воронку |
| 2 | HR заполняет email, пароль, название компании | HR | — |
| 3 | HR подтверждает email (переход по ссылке из письма) | HR | Активация аккаунта |
| 4 | HR входит в систему → видит пустой дашборд | HR | Состояние «пусто» |
| 5 | HR переходит в раздел «Сотрудники» → загружает CSV | HR | Загрузка данных |
| 6 | Система отображает список сотрудников | Система | Данные сохранены |
| 7 | HR переходит в раздел «Сценарии» → выбирает вопросы из библиотеки | HR | Сценарий создан |
| 8 | HR отправляет ссылку на опрос сотруднику | HR | Запуск процесса |
| 9 | Сотрудник проходит опрос в Telegram-боте | Респондент | Опрос завершён |
| 10 | Система анонимизирует ответы и отображает их в дашборде | Система | Данные в дашборде |
| 11 | HR открывает дашборд, видит распределение ответов, применяет фильтры | HR | Результат получен |
| 12 | HR нажимает «Экспорт PDF» → скачивает отчёт | HR | Результат сохранён |

| № | Контрольная точка | Метрика контроля | Фактическое значение |

### 2.3. Альтернативный сценарий (финальная версия)

**Название:** Сотрудник не проходит опрос → система отправляет напоминания

| Шаг | Действие | Роль |
| :--- | :--- | :--- |
| 1 | HR отправляет ссылку на опрос сотруднику | HR |
| 2 | Сотрудник не проходит опрос в течение 3 дней | Система |
| 3 | Система автоматически отправляет мягкое напоминание | Система |
| 4 | Сотрудник игнорирует напоминание → проходит ещё 2 дня | Система |
| 5 | Система отправляет второе (финальное) напоминание | Система |
| 6 | Сотрудник не отвечает → статус опроса «Пропущено» | Система |
| 7 | HR видит в дашборде статус «Нет ответа» | HR |

### 6.2. Инструкция по запуску и использованию (краткая)

**Запуск демоверсии:**
1. Перейдите по ссылке: `https://Exiti-demo.vercel.app`
2. Нажмите «Регистрация», введите email, пароль, название компании.
3. Подтвердите email (письмо приходит в течение 1 минуты).
4. Войдите в систему.

**Ключевой сценарий (5 минут):**
1. **Загрузите сотрудников:** Скачайте шаблон CSV → заполните → загрузите.
2. **Создайте сценарий:** Выберите 5–7 вопросов из библиотеки → сохраните.
3. **Отправьте опрос:** В списке сотрудников найдите тестового → нажмите «Отправить опрос».
4. **Пройдите опрос:** Перейдите по ссылке в Telegram → ответьте на вопросы.
5. **Посмотрите дашборд:** Откройте раздел «Аналитика» → примените фильтры.
6. **Экспортируйте отчёт:** Нажмите «Экспорт PDF» → скачайте файл.

**Тестовые данные:**
- CSV-файл с 5–10 сотрудниками (пример в папке `/examples`)
- Telegram-бот: `@ai_exit_bot`
