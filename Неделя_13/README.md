# Шаг 4. Инвестиционная история (Investment Thesis)

**Почему проблема существенна**

IT-компании теряют 15–30% сотрудников в год. Замена одного специалиста стоит 3–9 окладов ($15k–45k). HR не знает истинных причин ухода — сотрудники боятся писать правду в Google Forms. Рынок HR-tech растёт на 15–20% в год.

**Почему сейчас**

Рост удалённой работы усложнил сбор обратной связи. AI стал доступен и дёшев (NLP API). Компании ищут инструменты для удержания сотрудников, а не только для найма.

**Почему наше решение**

Exiti автоматически запускает exit-опрос в Telegram-боте, анонимизирует ответы, классифицирует причины ухода (выгорание, токсичный лид, зарплата) и даёт рекомендации по удержанию. Экономит HR 10+ часов в месяц.

**Почему команда**

Команда: аналитик, разработчик, дизайнер. Есть опыт в IT и HR. Проведены CustDev-интервью с 15+ HR-директорами, получены первые LOI.

**Почему масштабируемо**

SaaS-модель (подписка от $199/мес). Каналы: LinkedIn, Telegram-сообщества, партнёрства с HR-консультантами. Рынок — 5,000+ IT-компаний в РФ, затем СНГ и Европа.

**Почему выгодно инвестору**

Вход на ранней стадии, проверенные гипотезы, понятный план роста. При выходе на 50 клиентов ARR = $120k, оценка компании по мультипликатору 5x = $600k (рост капитала 10–15x за 3 года).
